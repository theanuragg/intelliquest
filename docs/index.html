💻 Source Code

  • Browser Automation Layer
    Playwright-based browser control with click, fill, download, screenshot actions
    → src/browser/controller.py
  • Fara-7B Reasoning Engine
    Ollama integration with smart action generation, self-correction, and decision-making
    → src/reasoning/engine.py
  • OCR & Document Pipeline
    Tesseract integration with caching, text cleaning, and document processing
    → src/ocr/processor.py, src/ocr/pipeline.py
  • Agentic Orchestrator
    Main reason→act→observe→update loop with state management and self-healing
    → src/agent/orchestrator.py
  • FastAPI Server
    REST API for task management, status tracking, and file handling
    → src/api/server.py
  • Logging System
    JSON audit trails, action logging, and comprehensive event tracking
    → src/utils/logger.py

📋 Quick Reference

Start Commands

ollama serve # Terminal 1: Start Ollama
bash start.sh # Terminal 2: Start Quest
http://localhost:8000/frontend/ # Terminal 3: Open dashboard

API Endpoints

POST /tasks # Create new task
GET /tasks # List all tasks
GET /tasks/{task_id} # Get task status
GET /tasks/{task_id}/result # Get results
GET /tasks/{task_id}/audit # Get audit log
GET /health # Health check

✨ Key Features

  • Autonomous Browser Automation
    Playwright + Fara-7B reasoning for intelligent UI navigation
  • Document Processing
    OCR, text cleaning, classification, and structured extraction
  • Self-Correcting
    When actions fail, Fara-7B proposes corrections automatically
  • 100% Local
    No cloud services, no external APIs - everything runs locally
  • Comprehensive Logging
    Deep audit trails in JSON for compliance and debugging
  • REST API + Web UI
    FastAPI server with modern dashboard for monitoring
